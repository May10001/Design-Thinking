# 后端二实现计划

**目标：** 按项目后端方案交付数据层、任务接口、匹配建议和确认事务，供其他负责人联调。

**方案：** 以文档第 13 节为数据库迁移基准；使用 Pydantic 校验、SQLAlchemy 操作 SQLite；确认过程在 BEGIN IMMEDIATE 内进行并保存幂等响应。匹配模块通过注入异步 Agent 和脱敏函数接入其他负责人模块。

**步骤：**
1. 用真实临时数据库验证迁移、外键和时间字段，再实现数据层及模型。
2. 验证任务字段规范化、筛选和版本更新，实现任务 API。
3. 验证确认操作、原子回滚、并发版本冲突和幂等重放，实现确认 API。
4. 验证规则匹配、更新合并、不确定性和批量语义候选边界，实现匹配服务。
5. 执行完整测试及迁移检查，说明其他负责人需要接入的边界。

**约束：** 单用户由服务端配置确定；确认前不得修改正式任务；不持有数据库事务调用 Agent；SQLite WAL 运行时要求 3.51.3 或更高；保持文档字段与错误格式。
